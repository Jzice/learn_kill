# 卡牌扩展包清单

> 在基础牌堆（core，125 张）之上补齐原版三国杀缺失的卡牌。
> **卡名直接使用《三国杀》原版卡名**，规则内核同样沿用原版；`sub` 仍按引擎约定（装备牌为槽位名，锦囊为原版英文 key），
> 因此 `Card` 结构不变、`state_sync` 序列化结构不变，旧版客户端可正常解包。
>
> 真源：`src/data/cardCatalog.ts`（卡牌目录）· `src/data/cardPacks.ts`（卡包定义）。新增卡牌只需加一条目录记录。

## 三、范围边界

- **纳入**：卡牌层面的全量补齐（含国战专属牌）。
- **排除（后续独立阶段）**：国战玩法模式规则（双将、野心家、珠联璧合）、虎牢关模式规则（三英战吕布、援军 / 神兵阶段、吕布暴怒阶段）。
  理由：模式规则需重构身份 / 回合 / 胜负体系，与卡牌补齐属不同变更域，混合实施会放大回归风险。本次**只引入其卡牌，不引入模式流程**。
- **简化实现**：上表标注「简化实现」的卡，原版规则细节存在分歧或需要额外交互 UI（存粮取粮、花色限制等），本实现保留其**收益内核**并以更简单的方式落地，规则书与出牌提示均按实际生效规则描述。

## 四、启用方式与联机

- 单人：设置界面「牌库扩展包」面板多选，结果写入 `localStorage['xuetangsha_setup_v1'].cardPacks`。
- 联机：房主勾选后经 `room_state.cardPacks` 广播；加入方经 `guest_pref.cardPacks` 上报自己的选择；
  开局时房主取**自身选择 ∪ 各成员叠加** 交给 `buildDeck({ packs })`。
- 房主未开启的卡包不会出现在任何客户端的牌堆中；关闭某卡包即可隔离该包的所有改动。
