# 学堂杀 · 高中扩展包 50 将方案（v2.7.0）

> 目标：把「高中扩展包」（`PacketId='senior'`）的可选角色从 **15 名** 扩到 **50 名**，
> 玩法更多样有趣，并保持与初中 / 基础 46 将同一套 PP 战力预算。
> 本文件是本次改动的**唯一设计事实来源**。
> **v2 定稿**：经三轮审核（玩法多样性 / 数值均衡 / 工程可实现性）修订，封堵 8 个阻断项。

## 2. 设计原则

### 2.1 玩法多样
1. **一人一面**：每名新角色的两个技能在**至少三个机制维度**上区别于其他角色。
2. **配比**：每名角色 = **1 个主动技**（含 ★限定 / ♦拼点 / 知识考核）+ **1 个锁定/触发技**，
   保证「回合内有事做 + 回合外有反应」。
3. **每族封顶**：同一机制族（判定 / 反间 / 令其选择 / 控顶 / 受伤反制 / 受伤回血）内
   通过「命中条件 + 收益形式 + 技能二钩子」三元组区分，且各族成员数 ≤8。

### 2.2 趣味性
- **4 个特殊技类型**：★限定技 ×3（费曼 / 袁隆平 / 康熙）、☆觉醒技 ×1（拿破仑）。
- **3 个 46 将从未实装的机制维度**：
  - **学识经济** `gainKnowledge`（马克思 / 王阳明）—— 首次让「学识」成为主动技产物
  - **反伤** `reflect`（俾斯麦【关税同盟】）
  - **距离陷阱** `distTrap`（哥伦布【新航路】）
- **1 组对称设计**（v2 因引擎限制撤下，见 §7.2）：军令状原拟与诸葛亮【出师表】对称。

### 2.3 均衡（PP 战力预算）
沿用《游戏机制.md》§6.2 / §6.3。

- 单价：摸1牌 0.6 · 令敌弃1牌 1.0 · 1 伤 1.5 · 回1血 1.2 · 距离±1 0.5 · 上限+2 0.6 ·
  免疫 0.8 · 转化 0.9 · 拼点 1.0 · 反伤 0.7 · 学识1点 0.6 · 群体 0.8 · 咆哮变体 1.3。
- 折扣：主动技（AI 答题成功率 0.62）×0.65 · ★限定 ×0.4 · ☆觉醒 ×0.5 · ♦拼点 ×0.7。
- **预算带**：4 血 **1.6~2.4 PP**；3 血 **2.0~2.8 PP**。
- 校准规则：**R1** 概率分支命中率 ≥40% · **R3** 未命中分支有 ≥0.6 PP 保底 ·
  **R5** 群体收益人均 ≤1 张 · **R6** 禁止「受伤后纯摸 1 张」。

> v2 修订：原 §6.3 的「4 血 2.0~2.5 / 3 血 3.0~3.5」是**未折扣**口径的旧提法；
> 实测 46 将（含折扣）4 血中位 ≈1.9、3 血中位 ≈1.8，故改用以折扣后口径标定的区间，
> 与 46 将实测同尺度。

### 7.3 使用的原语与时机（全部已验证被引擎消费）

```
执行期：selfDraw selfHeal selfLoseHp targetDiscard targetLoseHp targetDamage
        targetDraw gainHand allDraw allHeal gainKnowledge shield costCard
        deckPeek toDeckTop judgeIf pointDuel guessSuit targetChoose multiDraw
        giveHand exchangeHand discardToHeal showHand trickDraw
聚合/钩子：handLimit extraDraw distMod distPlusToMe shunshouNoDist distTrap
          cardImmune reduceDamage reflect shaUnlimited
时机：active passive onDamaged onTurnEnd onUseShan onUseTrick
条件：hpLowest hpAtMost srcHandMoreThanMe srcHandGeMe srcSameSubject srcDiffSubject
      noTrickThisTurn noShaThisTurn noDamageDealtThisTurn
      playedThisTurnAtLeast handAtMost lastCardRed
```

> 关键约定：锁定技里的触发型效果统一用 **`at` 字段**挂载
> （`{ kind:'selfDraw', n:2, at:'onTurnEnd', cond:{...} }`），
> 使聚合型原语（`handLimit` / `extraDraw` / `distMod`）不被误执行，
> 触发型原语又能在正确时机被 `effectsAt` 收集。
