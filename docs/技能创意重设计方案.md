# 技能创意重设计方案（v2.1）

> 目标：跳出「弃牌换收益」的同质化窠臼，把技能落到**卡牌原生规则**与**学堂杀独有的答题成长系统**上。
> 本文档只做设计与方案；实施见文末「实施步骤」，实施完成后同步回写《游戏机制.md》。
>
> 📌 **状态：设计稿（v2.0.0 发布时尚未实施）**。v2.0.0 交付的是声明式技能引擎（46 角色 93 技能全登记表化）；
> v2.1 的免疫 / 转移 / 距离陷阱 / 知识考核 / 装备改造机制在本文档定稿后按「实施步骤」落地。

## 一、问题诊断

v2.0 的 93 个技能虽然机制维度已大幅分散（26 类原型），但**主动技的费用几乎清一色是 `costCard`（弃 1~2 张手牌）**：

| 统计项 | 改版前 |
|---|---|
| 带「弃手牌」费用的主动技 | **16 个**（占主动技约 6 成） |
| 纯免疫 / 转移类技能 | 4 个（焚书、空城、结构式、免疫） |
| 指定牌名免疫 | **0 个** |
| 效果转移（锦囊 / 杀） | **0 个** |
| 以「答题」替代费用 | **0 个**（答题只是门槛，付费仍靠弃牌） |

后果：玩家体感是「每回合弃一张牌换个效果」，弃牌成为唯一通货，花样感不足。

## 二、设计原则（P1–P5）

- **P1 去弃牌化**：主动技优先用「答题 / 判定 / 顺序 / 距离 / 身份」等非手牌代价；手牌费用只保留在「语义即代价」处（同花色押韵、等位基因成对、军令状）。
- **P2 卡牌规则优先**：能引用牌名（万箭齐发 / 南蛮入侵 / 闪电）、花色、点数、距离、出牌顺序、判定区的位置，就不自定义数值。
- **P3 攻防都要有创意**：防御不止「弃牌免伤」，而用**指定牌名免疫**、**效果转移**、**距离陷阱**；进攻不止「造成伤害」，而用**改变目标**、**反转抉择**、**军令状**。
- **P4 学科即机制**：每位名人的机制必须能从其成就「一句话讲通」（法拉第→避雷、墨子→非攻、卢瑟福→散射偏转）。
- **P5 保留既有旋钮**：主动技仍须答题（AI 0.62），所以主动技可以设计得比触发技更「超模」而仍平衡。

## 三、新增机制原型库

### 3.1 指定牌名免疫 `cardImmune`

```ts
| { kind: 'cardImmune'; names: string[] }   // 不能成为这些牌的目标
```

- 诸葛亮·**【东风】**（头脑风暴备选）：不能成为【万箭齐发】的目标——*借东风，箭雨不侵*。
- 墨子·**【非攻】**：不能成为【万箭齐发】与【南蛮入侵】的目标——*非攻：反对不义之战*。
- 法拉第·**【避雷针】**：不能成为【闪电】的目标——*法拉第笼，雷电不侵*。

> 三国杀原版「诸葛亮无手牌时不能成为杀的目标」是**空城**；「东风」是社区常见衍生设计，二者不冲突。本期诸葛亮定稿仍为观星 + 空城 + 出师表（第四轮确认），【东风】列为备选变体。

### 3.2 指定花色免疫 `suitImmune`

```ts
| { kind: 'suitImmune'; suits: ('♠'|'♥'|'♣'|'♦')[] }   // 该花色的牌对你无效
```

- 巴斯德·**【免疫】**：♦方片的牌对你无效 + 火雷伤害 −1——*疫苗只对特定「菌株」（花色）生效*。

### 3.3 距离陷阱 `distTrap`

```ts
| { kind: 'distTrap'; min: number }   // 计算距离 > min 的角色不能对你使用【杀】
```

- 徐霞客·**【探险】**：计算距离时无视其他角色的 +1 马；**与你距离大于 1 的角色不能对你使用【杀】**——*游记所至，山川险阻，远敌难近*。

### 3.4 转移锦囊 `trickRedirect`

```ts
| { kind: 'trickRedirect' }   // 成为锦囊目标时，可转移给另一名角色
```

- 墨子·**【兼爱】**：当你成为锦囊牌的目标时，你可将此牌转移给另一名角色（每回合限一次）——*兼爱：替人承受*。

### 3.5 转移【杀】 `shaRedirect`

```ts
| { kind: 'shaRedirect' }   // 成为【杀】目标时，可转移给另一名角色
```

- 卢瑟福·**【散射实验】**：当你成为【杀】的目标时，你可将此【杀】转移给另一名角色（每回合限一次）——*α 粒子被原子核散射偏转*。

### 3.6 知识考核替代费用 `quizGate`（本题最大特色）

主动技**不再弃牌**，改为「答一道**本科目**的题」作为费用：

```ts
// 实现方式：SkillDef.cost 留空 + kind:'active'，invokeActive 已有的答题门槛即成为唯一费用
// 新增可选 cond：答对 → 完整效果；答错 → 保底/无事（由 effects 分支表达）
```

- 笛卡尔·**【坐标系】**：答一道数学题 → 答对则令一名角色判定，红色你摸 2 张。
- 普朗克·**【量子】**：答一道物理题 → 答对则连续判定直到偶数，获得全部判定牌。
- 林则徐·**【虎门销烟】**：答一道历史题 → 答对则令所有其他角色各弃 1 张，然后你摸 1 张。
- 凯库勒·**【苯环】**：答一道化学题 → 答对则令一名角色摸 2 张，然后其选择：交给你 2 张 / 受你 1 伤。

> 这正是学堂杀独有旋钮：**把「弃牌通货」换成「知识通货」**，与「答题即成长」主线完全同构。

### 3.7 装备改造机制（v2.1 追加）

装备区（武器 / 防具 / 双马）不再只是静态加成，而成为**可转化、可失效、可计量**的资源。

```ts
/* 装备牌当指定牌使用（复用既有 convert 原语的 from.type='equip'，无需新原语） */
| { kind: 'convert'; from: { type: 'equip' }; to: 'sha' | 'shunshou'; limit?: 'perTurn' }

/* 装备失效：其他角色装备区中指定槽位的牌对你无效 */
| { kind: 'enemyEquipVoid'; slots: ('weapon' | 'armor' | 'horsePlus' | 'horseMinus')[] }

/* 马政：装备区每有一张马，你计算距离额外 −n */
| { kind: 'horseDist'; n: number }
```

- 李四光·**【地质锤】**：你可将一张**装备牌当【杀】**使用（每回合限一次）——*地质锤就是武器*。
- 郑和·**【航海图】**：你可将一张**装备牌当【顺手牵羊】**使用（每回合限一次）——*按图索骥，取人财物*。
- 墨子·**【非攻】**：锁定技，你不能成为【万箭齐发】与【南蛮入侵】的目标；**其他角色的武器与防具对你无效**——*非攻：收缴天下兵器*。

> 「装备失效」的结算点：`useSha` 的诸葛连弩 / 青釭剑判定、`distBetween` 的对方 ±1 马、`shaDamage` 的防具减伤，统一在**目标侧**查询，不影响装备持有者本身。

## 八、实施步骤

1. **`src/core/types.ts`**：新增 5 个原语 `cardImmune / suitImmune / distTrap / trickRedirect / shaRedirect`（已在改版前落地）+ 装备类 `enemyEquipVoid / horseDist`。
2. **`src/game/skillEngine.ts`**：新增查询 `cardImmuneTo / suitImmuneTo / distTrapOf / trickRedirectOf / shaRedirectOf / enemyEquipVoidOf / horseDistOf`；
   `canBeTarget` 增加 `cardName / cardSuit` 两个可选参数。
3. **`src/game/actions.ts`**：
   - 南蛮 / 万箭 / 五谷 / 桃园 / 乐不思蜀 / 闪电 / 决斗 / 过河拆桥 / 顺手牵羊的目标过滤处传入牌名与花色；

## 九、风险与缓解

| 风险 | 缓解 |
|---|---|
| 转移目标导致无限连锁（A 转给 B，B 再转给 A） | 转移时排除原使用者与原目标；每回合限一次 |
| 指定牌名免疫使某张牌完全无法使用 | 仅对「群体 AOE + 闪电」开放，单体锦囊不接入，避免单卡锁死 |
| 距离陷阱与「距离 −1」叠加后永不触发 | 徐霞客的陷阱阈值设为 1，且保留无视 +1 马；阈值与原距离修正解耦 |
| 答题替代弃牌后主动技过强 | 维持答题门槛（AI 0.62）折扣 ×0.65，且答错即浪费本回合技能次数 |
| 装备失效导致诸葛连弩 / 青釭剑完全报废 | 仅限「武器 / 防具」两槽且仅对持有者本人判定；双马不纳入，避免距离体系崩坏 |
| 装备牌当杀 / 当顺手牵羊与「丈八蛇矛（两手牌当杀）」叠加 | 转化技记入 `skillUse` 每回合限一次，且不复制卡牌对象，无 id 污染 |
| 联机同步 | 转移选择复用 `waitChoice`，无新协议字段 |
