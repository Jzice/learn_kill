## 1. 游戏目标（身份局）

| 身份 | 图标 | 胜利条件 |
|---|---|---|
| 主公 👑 | 公开 | 消灭所有反贼与内奸 |
| 忠臣 🛡️ | 隐藏 | 主公存活并消灭所有反贼与内奸 |
| 反贼 ⚔️ | 隐藏 | 杀死主公 |
| 内奸 🦊 | 隐藏 | 最后与主公单挑并获胜 |

身份配置（`ROLE_CONFIG`）按人数：

| 人数 | 2 | 3 | 4 | 5 | 6 | 7 | 8 |
|---|---|---|---|---|---|---|---|
| 配置 | 主/反 | 主/反/内 | 主/忠/反/内 | 主/忠/反/反/内 | 主/忠/反×3/内 | 主/忠×2/反×3/内 | 主/忠×2/反×4/内 |

- 玩家可在大厅**预选身份**（随机/主公/忠臣/反贼/内奸），否则随机。
- 主公开局体力 +1，身份全场公开；其余身份隐藏，**阵亡后自动公开**。
- **一局结束时揭示所有角色身份**（含仍存活者）：座位列表与结算面板「本局战绩」不再显示「身份未知 / ???」，战报追加一条身份揭晓汇总；联机由房主结算后随 `state_sync` 下发。
- 座位按环形排列，**本人永远显示在第一位**（`displayOrder`）。

## 2. 回合流程

```
回合开始（重置 杀 / 技能 / 转化技计数 / 禁杀 / 乐不思蜀 / 酒的加成 / 花色收集 标记）
  ├─ 0. 准备阶段（判定前）：观星 / 周期律改牌序；觉醒技判定（杜甫·沉郁、司马迁·忍辱负重）；
  │     辐射标记在其回合开始时移除 1 枚并结算 1 点伤害
  ├─ 1. 判定阶段：从后往前结算判定区
  │     乐不思蜀：判定非红桃 → 跳过出牌阶段（仅本回合，下回合自动恢复）
  │     闪  电：判定黑桃 2-9 → 3 点伤害；否则移至下家判定区
  ├─ 2. 摸牌阶段：摸 2 张
  │     孙子·兵法可改为「获得至多两名其他角色各一张手牌」；华罗庚·优选法额外摸 1 再按奇偶决定是否弃 1
  ├─ 3. 参悟（可选）：答对多摸 1 张 + 学习奖励
  ├─ 4. 出牌阶段：循环出牌 / 发动技能（每回合 1 次主动技能，需先答题），直到选择"结束出牌"
  └─ 5. 弃牌阶段：手牌数 > 体力上限部分需弃置（缀术/元素/数论等提高上限；屠呦呦/祖冲之可将特定牌置顶而非弃置）
       回合结束：据守翻面（孟子·王道）、军令状结算（诸葛亮·出师表）、最后一张牌类型连锁（朱自清·荷塘月色）
```

## 3. 核心机制：答题即成长

答题是贯穿全局的成长系统，答对题目获得**学识（🔮）**并触发学习奖励：

- **学识**：可抵伤害（2 点挡 1 伤）、1 点当闪、濒死自救（1 点回 1 血）
- **护盾（🛡️）**：1 点挡 1 点伤害
- **连击（⚡）**：连续答对累计；3 连击摸 1 张、5 连击回 1 血 + 1 护盾、7 连击学识 +2
- **随机奖励**（答对时 roll，档位 0.30 / 0.55 / 0.72 / 0.88）：护盾 / 摸牌 / 回血 / 下张杀 +1 / 额外学识
- **科目精通**：同一科目答对 5 次 → 下张杀 +1；本阵营科目答对 → 额外 +1 学识并摸 1 张
- **技能挑战**：主动技能必须先答题，答对方可发动（失败则浪费本回合技能次数）

题库结构：`{ s:科目, kp:知识点, q:题干, o:选项[4], a:正确下标 }`，按 12 年级 × 9 科组织；
`pickQ` 优先从答题角色的科目/阵营科目中抽取（50%/70% 概率）。

### 回合限时（开局选项）
- 对局设置「回合限时」面板可开启：不限时，或每回合每次决策单独限时 10 / 20 / 30 秒
- 开启后，真人玩家的每个决策环节（出牌 / 出闪 / 濒死 / 弃牌 / 目标选择 / 无懈响应 / 答题）各自独立计时；超时按该环节默认规则自动处理并跳到下一步
- 默认处理：出牌=结束出牌 · 目标=取消 · 出闪=承受伤害 · 濒死=放弃 · 弃牌=自动弃一张 · 无懈/一般选择=不响应 · 答题=答错
- AI 不计时；联机由房主统一计时，倒计时截止时间戳随 `state_sync` 下发，客人端同步显示剩余秒数

### 学习档案与首页复习
- 以题干哈希为 key 记录每题的**答错次数 `w`** 与**连对次数 `c`**（`PROFILE.quizRec`，见 `profile/quizbook.ts`）；
  连对达 `MASTER_STREAK = 3` 即视为掌握，后续不再抽到
- 抽题权重：错题 10 > 同知识点 3 > 新题 1，已掌握 0；错题越多，「优先抽错题」的概率越高（15%~60%）
- **首页「我的学习情况」面板**（`ui/study.ts`）展示：统计条（累计作答 / 正确率 / 已掌握题 / 待复习错题）、
  按「学科 · 知识点」聚合的掌握进度、**待复习错题**（点击展开原题选项与正确答案，可一键「我已复习」推进掌握）、
  **已攻克错题**（曾错但已掌握，单独折叠列表）
- 展开解析时才按记录所属年级动态加载题库，首屏不加载任何年级题库（懒加载不变式）

### 知识图谱（知识点讲解 + 知识脑图）
- 数据来源：与题目同片的讲解 `k`（知识点 → 概要 / 要点 / 易错）与关系 `r`（`prereq` 前置 · `contains` 包含 · `apply` 应用 · `contrast` 对比），
  由 `scripts/build-banks.mjs` 从 `data/knowledge/<学期>/<学科>.tsv` 与 `<学科>.rel.tsv` 编目注入 `public/banks/<学期>/<学科>.js`
- 题库浏览页（`ui/bank.ts`）顶栏三视图：**📖 题目 / 📘 讲解 / 🧠 脑图**（`ui/knowledge.ts`）
  - 讲解视图：按「学科 → 单元」分组的知识点卡片，展开显示概要、要点、易错提示、关系，卡片上带题量与掌握度徽标
  - 脑图视图：SVG 关系图，按前置关系分层布局（前置在上、后继在下），四类关系分色分线型并带箭头；
    点击节点高亮并在下方显示讲解详情与关系；未选学科时自动挑一个有讲解的学科
  - 卡片与详情里的「🔍 相关题目」会跳回题目视图并以该知识点作为搜索词
- 讲解 / 脑图仅在进入视图时加载对应学科分片，首屏不加载任何分片（懒加载不变式保持不变）

## 4. 卡牌体系

### 基本牌
牌堆共 **125 张**（基本 58 / 锦囊 45 / 装备 22）。

| 牌 | 数量 | 效果 |
|---|---|---|
| 杀（普通） | 20 | 对攻击范围内目标造成 1 点伤害，每回合限 1 张（诸葛连弩无限） |
| 火杀 | 5 | 同【杀】，造成**火属性**伤害（可被【藤甲】放大、触发连环传导） |
| 雷杀 | 5 | 同【杀】，造成**雷属性**伤害（触发连环传导） |
| 闪 | 15 | 抵消杀；也可用 1 学识 / 1 护盾 / 答对题代替 |
| 桃 | 8 | 回 1 血；濒死时可自救 |
| 酒 | 5 | 下张杀伤害 +1；**每回合限一次**（未打出杀则加成不保留到下一回合）；濒死时可自救 |

### 锦囊（14 种）
无中生有（摸 2）· 过河拆桥（弃 1）· 顺手牵羊（距离 1 内获得 1）· 决斗（轮流出杀，无杀者受伤）·
南蛮入侵（需出杀）· 万箭齐发（需出闪）· 桃园结义（全体回血）· 无懈可击（抵消锦囊）·
乐不思蜀（判定区）· 闪电（判定区，雷属性 3 伤）·
**借刀杀人**（令一名持武角色攻击你指定的角色，否则交出武器）·
**五谷丰登**（亮出等同存活人数的牌，从使用者起依次各取一张）·
**铁索连环**（横置 / 重置一名角色，或重铸弃此牌摸一张）·
**火攻**（目标展示一张手牌，你弃一张同花色手牌造成 1 点火属性伤害）

### 装备（15 种）
诸葛连弩（无限杀）×2 · 青龙偃月刀（杀被闪后可再出杀）· 丈八蛇矛（两张手牌当杀）·
**青釭剑**（无视目标防具）· **雌雄双股剑**（对异性用杀，对方令你摸一张或自弃一张）·
**贯石斧**（杀被闪后弃两张牌强制命中）· **方天画戟**（最后一张手牌为杀时可指定至多 3 个目标）·
**寒冰剑**（弃两张牌改为令目标弃两张牌，免除伤害）· **古锭刀**（目标无手牌时伤害 +1）·
八卦阵（判定红色视为闪）×2 · 仁王盾（黑色杀无效）·
**藤甲**（普通杀 / 南蛮 / 万箭无效，受到的火焰伤害 +1）×2 ·
**白银狮子**（每次受到的伤害最多 1 点，失去时回 1 血）· +1 马 / -1 马（影响距离）

### 连环与翻面（严格原版，两者独立）
- **连环（横置）**：【铁索连环】横置的角色受到**属性伤害**时，该伤害传导给所有横置角色，随后**全部重置**；传导伤害不再二次触发传导
- **翻面**：翻面角色跳过其下一个回合并翻回正面；不由铁索连环触发

### 距离与射程
`距离 = min(环形座位距, 反向座位距) + 目标+1马 − 自己-1马 − 距离技(万有引力/探险)`，最低 1；
射程默认 1（武器决定）。顺手牵羊额外要求距离 ≤1。

## 6. 角色与技能

- **46 名**历史/文化名人，分属九科，覆盖初一上 → 高三下 12 个年级（含 v1.9.0 扩充的 9 名）
- **角色池随年级累加**：选高年级时低年级角色全部可用（`charPoolForGrade`）
- **诸葛亮为全表唯一的三技能角色**：【观星】+【空城】（三国杀原版）+【出师表】（新增）
- 主公自动获得所属阵营主公技（9 个，`kind='lord'`）
- 技能**数据驱动**：定义集中在 `data/skilldefs.ts` 的 `SKILL_DEFS`，由 `game/skillEngine.ts` 统一分派（详见《架构设计》§3.1）。
  技能按「时机（20 种）+ 费用 + 次数限制 + 触发条件 + 效果原语（约 44 种）」组合，**一人一面**，不再跨角色复用同一实现。

> 技能标签：【锁】锁定技 · ★限定技（整局限一次）· ☆觉醒技 · ⚑标记技 · ♦拼点/对决 · 转化技 · **知识考核**（以答题替代手牌费用）。
> 「时机」：`主动`=出牌阶段点击发动（需先答题）· `触发`=条件满足时自动/询问发动 · `锁定`=常驻生效。
> **v2.1 起主动技普遍不再弃牌**：费用改为「答一道本科目的题」，答对才生效、答错浪费本回合技能次数——详见 §6.4；
> 装备区也可被技能改造（装备牌当杀 / 敌人装备失效）——详见 §6.5。

### 6.3 PP 战力预算模型

4 血无技能 = 0 PP；4 血预算 2.0~2.5 PP，3 血预算 3.0~3.5 PP。
单价：摸 1 牌 0.6 · 令敌弃 1 牌 1.0 · 1 点伤害 1.5 · 回 1 血 1.2 · 距离 -1 为 0.5 · 手牌上限 +2 为 0.6 · 每回合限一次伤害 +1 为 1.2 · 免疫 0.8 · 观星类 0.8 · 转化技 0.9 · 拼点 1.0 · 无双 1.2 · 咆哮变体 1.3 · 杀闪互换 1.1 · 反伤 0.7 · 突袭 1.0 · 据守 0.9。
折扣：主动技（须答题，AI 成功率 0.62）×0.65 · 限定技 ×0.4 · 觉醒技 ×0.5 · 拼点/对决类 ×0.7。
核心平衡杠杆：主动技有答题门槛，可设计得比触发技更「超模」而仍平衡。

> 实证校准：`scripts/balance.mjs` 用无头 AI 对战跑数百局，输出各身份 / 各角色胜率与「去身份实力」分档表（扣除身份占比带来的胜率偏差），用于把点数技能数值微调进 PP 预算区间。

### 6.4 v2.1 创意机制库（免疫 / 转移 / 距离陷阱 / 知识考核）

设计动机与完整推导见 [技能创意重设计方案.md](./技能创意重设计方案.md)。

| 机制 | 原语 | 效果 | 代表角色 |
|---|---|---|---|
| 指定牌名免疫 | `cardImmune` | 不能成为指定牌的目标 | 墨子·非攻（万箭齐发 / 南蛮入侵）、法拉第·避雷针（闪电） |
| 指定花色免疫 | `suitImmune` | 指定花色的牌对你无效 | 巴斯德·免疫（♦方片） |

| 转移锦囊 | `trickRedirect` | 成为锦囊目标时可转移给另一名角色（每回合限一次） | 墨子·兼爱 |
| 转移【杀】 | `shaRedirect` | 成为【杀】目标时可转移给另一名角色（每回合限一次） | 卢瑟福·散射实验 |
| 知识考核 | 无手牌费用的主动技 | 答一道本科目的题作为费用，答对才生效 | 笛卡尔·坐标系、柯西·极限、普朗克·量子、拉瓦锡·质量守恒、居里夫人·放射性、凯库勒·苯环、巴斯德·巴氏灭菌、雪莱·西风颂、秦始皇·统一、林则徐·虎门销烟、郦道元·水经注 |

**结算规则**：
- 免疫类在目标合法性过滤处统一判定（`canBeTarget`），AOE（南蛮 / 万箭 / 五谷 / 桃园）与判定牌（闪电 / 乐不思蜀）同样生效；
- 转移类经 `waitChoice` 询问，**不可转回原使用者与原目标**，防止无限连锁；
- 知识考核复用既有答题门槛（`invokeActive` → `askQuizForPlayer`），答错即浪费本回合技能次数，不产生额外消耗；
- 距离陷阱只约束【杀】，不影响锦囊、决斗与装备。

**弃牌技削减**：带手牌费用的主动技由 16 个降至 **4 个**（莎士比亚·十四行诗「弃两张同花色」= 押韵、孟德尔·分离定律「弃两张同点数」= 等位基因、诸葛亮·出师表「弃 1 张立军令状」、茅盾·批判「被无懈后可选择弃 1 牌反制」）——这四个的「弃牌」本身就是语义，不是通货。

> **诸葛亮【东风】（备选）**：锁定技，你不能成为【万箭齐发】的目标（借东风，箭雨不侵）。本期诸葛亮定稿仍为观星 + 空城 + 出师表，【东风】列为后续可选变体。

### 6.5 装备改造机制库（v2.1 追加）

装备区（武器 / 防具 / 双马）从「静态加成」升级为**可转化、可失效、可计量**的资源。

| 机制 | 原语 | 效果 | 代表角色 |
|---|---|---|---|
| 装备牌转化 | `convert`（`from.type:'equip'`） | 把装备牌当指定牌使用 | 老舍·骆驼祥子（装备→闪）、李四光·构造体系（装备→杀）、郑和·航海图（装备→顺手牵羊） |
| 装备失效 | `enemyEquipVoid` | 其他角色装备区指定槽位的牌对你无效 | 墨子·非攻（武器 / 防具失效） |
| 装备区计量 | `handLimit` + 装备张数 | 装备区每有一张，手牌上限额外 +1 | 凯库勒·结构式 |
| 装备免疫 | `immune(scope:'equip')` | 你的装备不能被【过河拆桥】【顺手牵羊】指定 | 凯库勒·结构式 |

**结算规则**：
- 装备转化复用既有 `convert` 原语（`from.type='equip'`），走 `canConvertAs` 虚拟可用牌查询，**不复制卡牌对象**；每回合限一次记入 `skillUse`。
- 装备失效在**目标侧**查询：`useSha` 的诸葛连弩（无限杀）/ 青釭剑（无视防具）判定、`shaDamage` 的防具减伤、`distBetween` 的对方 ±1 马，统一改为「若目标免疫该槽位则视为无效」。
- 装备失效**只限武器 / 防具两槽**，双马不纳入，避免距离体系崩坏；不影响装备持有者自身的效果。
- 与【丈八蛇矛】（两手牌当杀）叠加时，转化技仍受每回合一次限制，不会出现无限杀。

## 7. AI 行为

- 出牌优先级：发动主动技能（50% 概率）→ 装备全部装备 → 满血前吃桃 → 无中生有 →
  对范围内**敌方**出杀
- 敌我识别（`isEnemy`）：主公/忠臣视反贼内奸为敌；反贼视主忠为敌；内奸先打反贼、反贼死光后打主忠
- 答题概率：普通 0.6，技能 0.62；出闪优先用牌，再学识
- 随机台词（55% 触发率）：idle / attack / heal / skill / greet 五类

## 8. 联机流程（房主权威）

1. 房主创建房间（6 位数字房间号，PeerJS Peer ID = `xts-<房间号>`），客人凭号加入
2. 双方在大厅编辑个性化资料（昵称/头像/性别/心情），经 `hello_profile` 同步并在成员列表互见
3. 房主开始游戏：AI 补齐空位；`start_game` 下发全部玩家（含各自 identity）
4. 房主运行游戏循环，全量快照 `state_sync`（80ms 防抖）保持同步；
   轮到客人时下发 `choose_request`（4s 心跳重发），客人的 `choose_response` 唤醒房主侧 Promise
5. 房主要求客人答题：`ask_quiz_request(quizId)` → 客人本地作答 → `quiz_response(quizId)`
   （20s 超时按答错处理，迟到旧回复按 ID 丢弃）
6. 掉线玩家即时转 AI，房主等待中的选择/答题按默认项结算，游戏不中断
